# Amazon India Sales & Performance Dashboard

## Project Overview
This project focuses on analyzing Amazon India sales and order data using Microsoft Excel. An interactive dashboard was developed to help management monitor business performance and make data-driven decisions.

## Project Objectives
- Analyze overall sales and order performance.
- Monitor delivered, returned, and cancelled orders.
- Evaluate product and customer performance.
- Analyze payment methods and fulfilment trends.
- Understand geographical sales distribution.
- Present key insights through an interactive dashboard.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning and Analysis

## Key Performance Indicators (KPIs)
- Total Orders: 10,000
- Delivered Orders: 8,147
- Returned Orders: 485
- Cancelled Orders: 500
- Return Rate: 4.9%
- Cancellation Rate: 5%

## Dashboard Features
- Interactive charts and visualizations.
- KPI cards for important business metrics.
- Slicers for dynamic filtering.
- Analysis of sales, products, payments, fulfilment, and geography.

## Key Outcome
The dashboard provides a clear overview of Amazon India's order performance and helps management identify patterns and areas that may require improvement.
